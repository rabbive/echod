What am I seeing? — glossary (click to expand)

Leader — coordinator that accepts replicated writes for this term; only one should be leader at a time in a healthy cluster.

Term — monotonic election generation; goes up when a new election wins.

Max commit — highest commit index across nodes (replicated log applied).

Leaves — registered mock sensors; traffic shows up as replicated log entries.

Charts / broadcast table — live MQTT traffic. If nothing moves, check Socket.IO and MQTT indicators above (macOS often uses port 5001 if 5000 is taken by AirPlay).
